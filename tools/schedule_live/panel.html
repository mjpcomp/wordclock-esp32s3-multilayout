Daily schedule — configuration editor

This editor stores a schedule. It does not switch brightness mode or enable schedule output. Keep using the existing controls until output has been explicitly validated.

Waiting for scheduler configuration support.

Hardware readiness is not verified.

An empty changes list uses the all-day level. Zero means display output off, not controller or Wi-Fi shutdown.

An earlier target-reached time means tomorrow. Targets hold until the next change, including across midnight.

Apply stages the selected change locally; Save writes the draft. Add creates an instant change which you can then select and adjust.

After reconnecting or an uncertain save, reload and explicitly choose which version to keep. No automatic save retry occurs.
